# Phase 3 提示词：背景黑线形变

完成 `docs/PHASES.md` 的 Phase 3。背景黑线必须跨路由保持存在，在路由变化时从当前形状连续变成目标形状，并根据当前长页面的纵向滚动进度持续位移和弯折。

为简介、摄影作品、项目定义相同数量的归一化控制点。简介形状自由开放；摄影形状像穿过图片的取景路径；项目形状更结构化，连接内容节点。使用基于帧时间的阻尼插值，允许过渡中再次导航，不得先跳回起始形状。

主线为清晰细黑线，完整页面滚动中应上移约四分之一视口，并加入可辨认但克制的局部弯折、横向剪切和相位变化，保证页面顶部、中段与底部的轮廓一眼可区分。可有一条以明显更慢阻尼跟随的极淡回声线提示滚动方向。首尾端点必须沿相邻线段方向外推到视口外，并设置约 16% 视口的越界余量；初始渲染、滚动和每个路由插值中间帧都要重新强制该约束，屏幕内不能出现端点或线帽。将实际渲染曲线均匀采样并提供给波纹模拟，不能只暴露静态控制点。线条不覆盖关键文字，不阻挡点击。`prefers-reduced-motion` 下取消回声和长时间形变。

验收从每个页面分别切换到另两个页面，快速连续点击导航；在长页面顶部、中段和底部分别截图或观察，三个状态的黑线位置与轮廓必须无需仔细对比即可分辨，同时滚动过程保持连续；检查桌面与窄屏中线条主体仍在画面内，但两端始终完全位于画面外。
