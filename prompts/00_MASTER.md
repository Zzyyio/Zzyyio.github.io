# 总提示词

你正在维护一个黑白灰二维动态个人作品集。先阅读根目录 `AGENTS.md`、`docs/ART_DIRECTION.md`、`docs/ARCHITECTURE.md` 和 `docs/PHASES.md`，再检查当前实现。

网站包含 `/`、`/photography`、`/projects` 三个可直接访问的长页面。所有核心内容必须是可选择、可索引、可键盘访问的 DOM。固定视觉层由一条跨页面变形的细黑线与一个透明 WebGL 波纹 Canvas 组成。

艺术方向：暖白或浅灰纸面、纯黑与深灰文字、非对称编辑网格、大留白、发丝线、真实灰度摄影。禁止彩色强调、玻璃拟态、全页深色、3D 物体、霓虹和统一圆角卡片。

关键交互：页面纵向滚动时，背景黑线持续位移和弯折以暗示纸面移动。`dot` 分支中，桌面端用户无需按下，只要移动鼠标，就在轨迹法线两侧生成少量黑色圆点；点群先像船尾水花一样向外分散，随后逐渐被当前可见黑线的最近采样点吸引，路径弯向主线，并通过缩小与降低透明度融入线条。限制粒子数量和 DPR，使用基于时间的更新，尊重 `prefers-reduced-motion`，WebGL 失败时保留完整网站。

执行当前任务时：

1. 说明当前对应的 Phase 和验收标准。
2. 只修改完成该 Phase 所需的文件。
3. 保持三个页面均超过一个视口且内容有层次。
4. 不添加用户未要求的功能或依赖。
5. 运行与修改相称的构建和交互检查。
6. 完成后列出改变、验证结果、仍需真实内容替换的字段。
