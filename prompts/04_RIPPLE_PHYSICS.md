# Phase 4 提示词：点波纹、吸附与融合

完成 `docs/PHASES.md` 的 Phase 4。当前工作位于 `dot` 分支。使用透明 WebGL2 Canvas 和 `POINTS` 渲染点状波纹，Canvas 必须 `pointer-events: none`。

输入模型：桌面端不需要按下，任何有效鼠标移动都连续生成；触屏仍只在明确接触移动时反馈，避免阻止原生滚动。计算移动向量 `(dx, dy)`，归一化后得到切线和法线 `(-dy, dx)`。鼠标累计移动约 6px 后，在法线正负两侧各产生少量粒子，并沿反切线方向加入短距离偏移。

初始分散：参考物体划过水面形成的船尾水花，但只抽象为简洁黑点，不复刻照片颜色与泡沫纹理。新点首先沿正负法线向外运动，构成松散、略带随机但整体平衡的 V 形尾迹。点的尺寸约 1—3px，避免密集烟雾和大块黑团。

吸附模型：对屏幕上实际渲染、已响应滚动的背景黑线均匀采样。生命周期前段以扩散为主，中后段平滑增加吸引力；每个点寻找最近采样点并向其加速，同时使用速度阻尼和极轻微扰动，避免机械直线。进入约 24px 的吸收区域后同步减小尺寸与 alpha，最终像被黑线吸收。

性能：粒子总数不超过 240；DPR 不超过 1.5；不在动画循环中更新 React state；销毁时释放 program、buffer 和事件监听；限制长帧时间。

降级：WebGL2 不可用时静默取消点波纹，网站继续工作；减少动态效果时不连续生成；触屏不能阻止正常纵向滚动。

验收在不按鼠标键的情况下进行慢移、快速移动和折返移动，并在靠近及远离黑线处测试。确认点群先明显向轨迹两侧分散，再弯向黑线；靠近主线时缩小并消失，而不是在原地淡出。
