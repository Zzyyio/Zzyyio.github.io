# 实现架构

## 分层

```text
Semantic DOM
├── app/page.tsx
├── app/photography/page.tsx
└── app/projects/page.tsx
        │
Persistent frame
├── fixed navigation
├── route detection
├── SVG line field
└── WebGL ripple canvas
        │
Visual data
└── normalized route shapes
```

页面内容由服务端组件输出。`PortfolioFrame` 是客户端持久层，读取当前路径并驱动背景线与 WebGL 波纹。路由变更时，页面内容更新，视觉层保持同一套组件生命周期。

## 黑线

`lib/visual-shapes.ts` 为每个路由保存相同数量的归一化控制点，并根据全页滚动进度添加连续纵向漂移与局部弯折。形变后沿首尾相邻线段的方向外推端点，直到越过归一化视口至少 `0.16`，确保线帽不进入画面。`LineField` 使用基于帧时间的阻尼插值，再将点转换为平滑 Bézier 路径。主线快速响应，回声线慢速跟随。

端点越界约束还要在每帧插值完成后再次执行，因为两个都在视口外的目标端点相互插值时，中间状态仍可能穿回视口。初始 SVG 路径也必须使用已经外推的形状，避免首帧闪现端点。

渲染后的曲线会被均匀采样，并通过 `lib/line-runtime.ts` 暴露给 WebGL 模拟。这样波纹始终吸向屏幕上实际可见、已经响应滚动的曲线，而不是静态控制点。

控制点数量必须保持一致，否则不能直接逐点插值。新增路线时先定义形状，再将路线加入导航和路径解析。

## WebGL 点波纹

`RippleField` 使用 WebGL2 `POINTS` 渲染透明圆点：

1. 桌面端每次有效 `pointermove` 都计算切向量与法向量，无需按下；触屏只在明确接触移动时反馈。
2. 鼠标累计移动约 6px 后，在轨迹法线正负两侧各生成少量点，并沿反切线方向加入短距离随机偏移。
3. 新点先获得向外法线速度，前段以扩散为主，形成松散而对称的船尾水花轮廓。
4. 随生命周期推进逐渐增加黑线吸引力；每个点独立寻找当前可见曲线的最近采样位置。
5. 使用阻尼和极轻微扰动消除机械直线感，但保持黑白极简，不模拟真实泡沫材质。
6. 距离黑线变小时同步减小点尺寸和透明度，最终看起来被主线吸收。

WebGL Canvas 透明且 `pointer-events: none`，不能阻挡链接和滚动。

## 性能预算

- 点粒子上限：240。
- DPR 上限：1.5。
- 每帧不写 React state。
- 不加载 3D 模型、HDR、阴影或后期处理。
- 摄影图片使用本地资源、合理尺寸与懒加载。
- 长帧时间被限制，避免切回标签页后模拟爆炸。

## 降级

- WebGL2 不可用：背景 SVG 线和完整内容仍然存在，只取消波纹。
- 减少动态效果：不生成连续波纹，隐藏线条回声，保留链接状态。
- 移动端：单指垂直滚动优先；只有明确拖动意图时产生少量反馈。

## 后续可扩展点

- 使用 transform feedback 或纹理存储将模拟移到 GPU。
- 为项目增加独立详情路由，同时保持视觉层在布局中持续存在。
- 用 CMS 替换静态内容前，先保持当前 DOM 结构和图片比例字段。
